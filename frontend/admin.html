Dashboard

Estado general de usuarios, membresías y operación.

Como super administrador puedes gestionar usuarios, membresías y auditar el sistema. No puedes generar cobros, pagar ni operar a nombre de ningún usuario. La CLABE permanece enmascarada. El expediente de registro y validación se abre desde el perfil de cada usuario.
